Witaj w systemie BigOS!

Bigos to, przeglądarkowy system operacyjny napisany od zera. Odkryj bogate aplikacje, narzędzia i gry zintegrowane w jednym środowisku!

Aktualizacja 1.19

  • ✔️
    Modularna architektura - Przepisany kod na moduły!
  • ✔️
    Kompresor obrazów - Nowy silnik Canvas zdejmuje limit pamięci 5MB.
  • ✔️
    Program Nadzorca Systemu - Pokazujące listę aktualnie otwartych aplikacji oraz "symulowane" zużycie procesora (CPU) pokazuje le zajmuje pamięci RAM, Dysku..
  • ✔️
    Program Pogodynka - Wyświetla aktualną pogodę, temperaturę i prognozę na kolejne dni. Pobiera aktualne dane pogodowe z darmowego API po wpisaniu nazwy miasta..
  • ✔️
    Program Czasomierz (Zegar, Stoper i Minutnik): - Pozwala ustawić odliczanie czasu, stoper do mierzenia np. czasu gry oraz budzik. Gdy czas minie, system wyświetli systemowe powiadomienie (Toast) i zagra krótki dźwięk beep..
  • ✔️
    Program Tabelarz: - W pełni działający, prosty arkusz kalkulacyjny (kolumny A-E, wiersze 1-10). Posiada mechanizm formuł – jeśli wpiszesz w komórkę np. =SUM(A1:A5), system automatycznie podliczy wynik! Pliki zapisują się w formacie .csv w systemie lub można zapisac na PC. Funkcja =MIN(A1:A100) wyświetla najmnieszą wartość z kolumny. Funkcja =MAX(A1:A100) wyświetla najwiekszą wartość z kolumny. Funkcja =ŚREDNIA(A1:A100) wyświetla średnią wartość z kolumny
  • ✔️
    Program Zadaniowiec - Tablica Kanban. Dodawaj zadania, łap je palcem (lub myszką) i przeciągaj między kolumnami "Do zrobienia", "W trakcie" i "Zrobione". Zmiany są automatycznie zapisywane
